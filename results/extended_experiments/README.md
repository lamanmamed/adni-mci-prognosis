# Extended experiment results

Only aggregate outputs are stored here. Participant-level predictions and ADNI identifiers remain outside the repository.

`summary_metrics.csv` collects the main pooled metrics from the saved notebook outputs. `nested_cv_error_detection.csv` records the uncertainty/error-detection analysis, and `fusion_auc_bootstrap.csv` contains the paired bootstrap comparisons used in the fusion experiments.

The figures are exported directly from the completed notebooks before notebook outputs are cleared.
